# Algorithmic Methods of Data Mining — Homework 1

This repository contains the solutions for Homework 1 of the
Algorithmic Methods of Data Mining course.

The homework focuses on Python programming fundamentals and
algorithm implementation using HackerRank challenges.

## Repository Structure

- `scripts.py`: Python solutions for the assigned exercises.
- `printouts/`: PDF printouts or screenshots of completed HackerRank
  challenges.
- `README.md`: Description of the repository and its contents.

## Problem 1 — Python Fundamentals

This part covers Python programming concepts through HackerRank
challenges, including:

- Introduction and basic data types
- Strings, sets, and collections
- Date and time
- Exceptions and built-in functions
- Functional programming
- Regular expressions and parsing
- XML
- Closures and decorators
- NumPy

## Problem 2 — Algorithms

This part focuses on implementing algorithms in Python through
the following HackerRank challenges:

- Birthday Cake Candles
- Kangaroo
- Strange Advertising
- Recursive Digit Sum
- Insertion Sort — Part 1
- Insertion Sort — Part 2

## Submissions

The `scripts.py` file contains the Python implementations, while
the `printouts/` directory stores the corresponding HackerRank
submission evidence.
